Cloud API Keys

Cloud agents need API keys to connect to external providers. Paste each key below — we'll validate it before saving. All keys are optional; set whichever services you use.

Where to get keys:
• Groq — console.groq.com/keys (free tier available)
• GitHub — github.com/settings/tokens → Fine-grained token
• xAI / Grok — console.x.ai
• Anthropic — console.anthropic.com
• Gemini — aistudio.google.com/apikey (free tier available)
• Tavily — app.tavily.com (deep research, free tier)
