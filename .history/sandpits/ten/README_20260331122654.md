# Ten Sandpit

Workspace for Ten (Copilot / GPT-5.3-Codex).

## Layout
- proposals/: Draft and approved proposal docs
- logs/: Execution and review logs
- tests/: Focused validation tests for Ten-owned changes
- working/: In-progress artifacts and notes
- archive/: Completed proposal/test bundles

## Rules
- Proposal-first for mutating changes when ALM is active.
- Keep cross-agent review notes concise and traceable to proposal IDs.
- Mirror finalized change/audit evidence into canonical ledgers.
