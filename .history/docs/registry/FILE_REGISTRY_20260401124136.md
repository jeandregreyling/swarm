---

## Status Codes

| Code | Meaning |
| ------ | --------- |
| ACTIVE | In use, maintained, authoritative |
| LEGACY | Still runs but should be migrated away from |
| SUPERSEDED | Replaced by a newer file — do not edit, read only |
| ARCHIVE | Historical record — do not edit |
| SHADOW | Dangerous: duplicate of a canonical file, must not be imported directly |
| CONFIG | Configuration data, edit with care |
| DATA | Runtime data file, do not hand-edit |

---

## Rule for AI Agents

Before creating ANY new file:
1. Check this registry — does a suitable file already exist?
2. If yes: append to the existing file instead.
3. If no: create the file AND add it to this registry in the same operation.
4. Run `ops/scripts/log_change.sh` to record the change in both canonical ledgers.
