## 7. Incident Addendum (Localhost outage + ALM stability)

Audit window: 2026-03-30 01:51-02:03 UTC
Auditor: Copilot (Ghost Layer)

### Incident summary
- User reported localhost unavailable and requested ALM + self-audit verification.
- Port 5050 process state was inconsistent during restart attempts and UI generated high-frequency `/api/alm/status` traffic.

### Root causes found
- Theme ALM sync JS in `frontend/theme_engine.py` used `MutationObserver` + `initALMData()` fetch loop, causing repeated status polling under dynamic DOM mutation.
- Runtime path split existed between active worktree launch and hardcoded `sys.path` base (`/home/seven/swarm`) for imports.

### Fixes applied
- Restarted Fridays on port 5050 with ALM and self-audit flags enabled.
- Patched ALM theme JS to:
  - guard re-entrant ALM apply
  - throttle runtime ALM fetches
  - avoid fetch on mutation callback
  - use a low-frequency refresh timer (30s)
- Added ALM status endpoint cache in `frontend/terminal.py` (`2s` TTL) to keep API stable under aggressive polling.
