⚡ Agents — what this screen does

Each card represents one AI agent running inside the swarm. The toggle switch takes an agent offline instantly — any pipeline call to that agent returns [offline] and the swarm continues without it.

Temperature controls how creative or deterministic each model is. Lower = more focused and consistent. Higher = more varied and exploratory. Changes take effect on the very next call — no restart needed.

GemmaOrchestrator. Reads all other agents, makes the final call. Low temp = reliable routing.
LLaMAFast first-pass researcher. Medium temp = useful but not hallucinating.
QwenDeep analyst. Higher temp = more original takes, debate mode benefits from this.
LibrarianTriage + tagging. Very low temp = consistent classification.
DuckSanity checker. Very low temp = strict binary YES/NO verdicts.
SnifflesPattern auditor. Low temp = precise pattern detection.
EightSAP specialist. Higher temp = more nuanced SAP analysis.
NineSystem architect (Claude API). Toggle disables Ghost Circle calls. No temperature control — model is fixed.
GhostHuman operator. Listed for completeness — toggle has no effect.

Toggle state and temperature changes are live but not persisted — a service restart resets them to defaults.

🧠 Memory — what this screen does

    
This is the swarm's long-term knowledge store. Every time a ticket closes, Librarian reads the conversation and writes key facts, answers, and insights here with an importance score.

    

      
Shared poolThe memory table — facts and answers any agent can reference.

      
LLaMA / Qwen / Gemma / EightEach has its own private table for agent-specific knowledge.

      
Importance 9-10Critical facts. Always surfaced.

      
Importance 5-8Useful knowledge. Default search range.

      
Importance 1-4Context and ephemeral notes.

    

    
Use the agent filter to scope results to one agent's memory. Use the delete button on any card to permanently remove a memory entry.

    
  







  

    
🎫 Tickets — what this screen does

    
Every question that enters the swarm creates a ticket. A ticket tracks the full lifecycle of one question from intake to close.

    

      
Statusopen = in pipeline. closed = answered. failed = error.

      
Duck verdictYES = answer addressed the question. NO = Duck flagged a problem.

      
Routing badgesSAP, WEB, DEBATE, IDENTITY — what Gemma decided during FL-001 routing.

    

    
Click any row to open the full ticket detail — question, every agent's response, Duck verdict and reason.

    
Use the delete button on a row to permanently remove a ticket and its notes. This cannot be undone.

    
  







  

    
🖥️ System — what this screen does

    
Live hardware health of seven-potato. This is the same data Librarian injects into context when you ask a system question (IS_SYSTEM routing).

    

      
CPUUsage % across all cores. i5-10500, 6 cores.

      
RAM32 GB physical + 128 GB swap on fast NVMe = ~160 GB effective.

Servicesswarm-listener, swarm-telegram, swarm-terminal status.

    

    
Click Refresh to pull a fresh snapshot. Data is not live-streaming — it is a point-in-time read.

    
  







  

    
📁 Sandpits — what this screen does

    
The Fridays action layer gives agents the ability to read/write files, run shell commands, and browse the web. Sandpits are the controlled workspaces where this happens.

    

      
Level 0Read-only. List and read files. No writes.

      
Level 1Write to sandpit/L1/ only.

      
Level 2Write + whitelisted shell commands.

      
Level 3Write + web browsing.

      
Level 4Full whitelisted shell + elevated commands.

    

    
Every operation is logged to sandpit_log. Sniffles audits these entries for anomalous patterns and writes to sniffer_memory. Sniffles never runs while a pipeline is active.

    
  







  

    
⚙ Skills — what this screen does

    
Skills are named, dispatchable actions the swarm can perform on demand. Run them here, via email, or via Telegram.

    

      
shellRun a whitelisted shell command. SKILL shell df -h

      
browseFetch and read a URL. SKILL browse https://example.com

      
file_readRead a sandpit file. SKILL file_read notes.txt

      
file_writeWrite a sandpit file. SKILL file_write notes.txt hello

      
searchWeb search. SKILL search latest AI news

      
remindSend Ghost a reminder email. SKILL remind Check the lease

      
scheduleCreate a scheduled task. SKILL schedule daily 09:00 QUESTION news?

      
listList available skills. SKILL list

    

    
All skill runs are logged to ghost_circle. Output is capped at 4096 characters.

🔑 Access — what this screen does

    
Every sender that contacts the swarm is classified on arrival. This screen lets you manage those classifications directly without sending a command email.

    

      
TrustedFull pipeline. Question goes into the queue, gets answered by the agents, reply sent back.

      
NotificationSilent filing only. Email or message received and marked read. No pipeline, no reply. Also covers senders you've actioned as IGNORE.

      
UnknownNot in either list. Librarian auto-triages — ANSWER fires the full pipeline, IGNORE files silently and notifies you.

    

    
Channel prefixes: Email senders are stored as plain addresses. Telegram senders are stored as telegram:chat_id. WhatsApp will use whatsapp:number.

    
Moving a sender between lists takes effect on the next message — no restart needed.
