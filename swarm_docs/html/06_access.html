The 27 Constraints

These rules must never be broken. When in doubt, refer to this list.


Architecture

  • Librarian only receives content to tag — never questions, never raw email bodies

  • Sniffles never interrupts an active queue — waits for queue quiet 1+ hour

  • Duck runs after every ticket close, no exceptions

  • Claude never speaks directly to email senders — mentor not driver

  • Gemma routes FIRST — no web search before Gemma reads the question

  • IS_IDENTITY=yes only for swarm questions, agent names, and Ghost

  • The Librarian never speaks

  • Claude API is the last thing built — local pipeline must be stable first

  • Ghost Circle dashboard is read-only when built

  • Terminal bypasses email but still creates tickets and runs Duck


Hardware & Security

  • nvme0n1p1 (EFI) is untouchable — ever

  • OLLAMA_HOST=0.0.0.0 always in ollama service override

  • config.py is never shared or printed

  • Ollama port 11434 — Tailscale only

  • Open WebUI port 3000 — Tailscale only

  • Swarm Terminal port 5050 — Tailscale only

  • ANTHROPIC_API_KEY in /etc/environment — never in config.py

  • Tailscale keys never stored in the swarm repository

  • Memory limits set by importance threshold — never by count


Eight & Fridays

  • Eight is a thinking partner — reasons and debates, never executes against SAP

  • Eight corrections replace memories, never delete history (Sniffles flags old entry)

  • All agents start Fridays Level 1 (own sandpit only) — earn higher through reliability

  • Nothing leaves a sandpit for the real system without Duck checking it

  • All Level 3+ real-system writes logged to ghost_circle

  • All Level 4+ shell executions logged to ghost_circle

  • Skills and platform connectors follow same trusted sender model as email

  • Specialist agents (Eight, Nine...) always use Seven's infrastructure — no standalone pipelines

  • Sniffles audits sandpit_log with same rules as memory pools



Tailscale

Ollama (11434), Open WebUI (3000), and Swarm Terminal (5050) are locked behind Tailscale. Public internet cannot reach them.

# Install on any new device

curl -fsSL https://tailscale.com/install.sh | sh

sudo tailscale up

tailscale ip -4 # confirm connection

One-Click Approval

When an unknown sender emails Seven, Ghost receives an email with three clickable links. Each link is a UUID token (single-use, stored in approval_tokens table). Clicking Trust immediately processes any pending emails from that sender. Text commands still work as fallback.
