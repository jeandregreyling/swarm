Step 4a — Standard Pipeline (consult_stage2)

  • Qwen reads LLaMA's answer before forming its own

  • Qwen searches Tavily independently

  • Gemma compares answers — disagreement detected → debate.py fires

  • If debate: LLaMA R2 → Qwen R2 → Gemma judges with full transcript

  • Gemma may call Claude API if stuck (problem type determines cache key)

  • Gemma may search Serper/Google if authoritative source needed

  • Verdict → memory_gemma → promote_to_verified (importance 9)

  • Email 2 sent: Qwen answer + debate transcript (if any) + Gemma final verdict


Step 4b — SAP Pipeline (consult_stage_eight)

  • Eight/Functional answers — config logic, standard SAP approach

  • Eight/Technical reads Functional — ABAP, FMs, what the code actually does

  • Eight/Devil reads both — edge cases, retro traps, ECP gaps, what was missed

  • Gemma synthesises across all three voices — final SAP verdict

  • Verdict → memory_eight (importance 7-9) + promote_to_verified

  • Email 2 sent: Three voices + Gemma SAP verdict


Step 4c — System Pipeline (IS_SYSTEM=yes)

  • monitor.librarian_health_summary() called for live data

  • Returns: RAM/CPU/temp/disk/memory pool counts/consultation stats

  • No web search. No agent deliberation. Live data only.


Step 5 — Librarian Close (ticket.librarian_close)

  • Indexes Gemma's verdict to shared memory (importance 9)

  • Sends final email to sender

  • Marks ticket CLOSED

  • Duck sanity check runs inside close:

  • YES → logged to duck_log, done

  • NO → flag_for_sniffles(), ticket still closes


Step 6 — Sniffles (async, when triggered)

  • Triggered: 1-in-5 random chance on ticket close

  • Triggered: Duck flagged something AND queue quiet 1+ hour

  • Never interrupts active queue

  • Audits all 5 memory pools + sandpit_log

  • PASS: logged. WARN: Ghost + agents notified. FLAG: Ghost email immediately.

SSE Streaming

Terminal uses Server-Sent Events (SSE) for real-time streaming. Each agent's response streams as it's generated. The pipeline runs in a background thread — the browser receives events via /stream/<ticket_number>.

Timeout set to 900 seconds — Eight pipeline can take 8-12 minutes on this hardware (4 sequential model calls).



One-Click Approval Flow

When an unknown sender emails Seven, the Ghost receives a notification email with three clickable links: Trust, Notify, Ignore.

  • Each link contains a UUID token stored in the approval_tokens table

  • Tokens are single-use — clicking the link marks it consumed

  • Trust: adds to trusted_senders, processes any pending emails in background thread

  • Notify/Ignore: adds to notification_senders

  • Text commands (TRUST email@address.com) still work as fallback

  • Terminal handles the /approve/<action>/<token> endpoint
