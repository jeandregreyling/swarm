Quick Reference — Ghost Commands

Command

Effect

TRUST email@address.com

Add to trusted. Process any pending emails immediately.

NOTIFY email@address.com

File silently. No response ever.

IGNORE email@address.com

Same as NOTIFY.

REMOVE email@address.com

Remove from trusted list.

REMOVENOTIFY email@address.com

Remove from notification list.


⚠ One-click approval links also available — Ghost receives Trust/Notify/Ignore links in unknown sender emails. Single-use UUID tokens. Terminal handles /approve/<action>/<token>.
