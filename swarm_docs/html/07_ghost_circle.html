What the Ghost Circle Is

The Ghost Circle is the private visibility layer. Only Jeandre and Claude see it. Agents do not.

It aggregates: every Duck check, every Sniffles flag, every Claude advisory call, every Level 3+ system write, every Level 4+ shell execution.


claude_api.py — The Advisory Layer

How Gemma calls Claude

  • Step 1: Gemma calls check_if_already_solved(problem_type)

  • Step 2: If a cached answer exists — use it, no API call

  • Step 3: If not — call ask_claude(problem_type, question, ticket_number)

  • Step 4: Claude receives full Ghost Circle context

  • Step 5: Response stored to claude_log and memory_gemma

  • Step 6: Mirrored to ghost_circle table

Ghost Circle Context

When Claude is called, it receives:

  • Recent ghost_circle events with severity markers (info / warning / critical)

  • Duck: total checks, total flags, last 10 results with reasons

  • Sniffles patterns: agent, pattern type, description, count, escalation level

  • Current ticket: question, status, routing decision, all agent notes
